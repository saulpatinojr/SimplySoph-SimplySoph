# SimplySoph Platform Overview

## Purpose & Vision

SimplySoph is a modern, Gen Z-focused content management platform designed specifically for fashion creators. The platform empowers creators to showcase their unique style, share fashion insights, and build authentic personal brands through professional content management tools.

## Core Functionality

### Content Creation & Management
- **Rich Text Blog Editor**: Professional Tiptap-based editor with formatting toolbar, image insertion, and responsive design
- **Video Content Management**: Complete CRUD operations for video uploads with admin interface
- **Photo Gallery System**: Album-based photo organization with category support
- **Content Categories**: Organized content structure for blogs, videos, and photos

### Admin Dashboard
- **Authentication & Authorization**: Firebase Auth with Google OAuth and role-based access
- **Content Management**: Comprehensive CRUD operations for all content types
- **Analytics Dashboard**: Performance tracking and engagement metrics
- **User Management**: Creator profile management and admin controls

### Public Features
- **Responsive Design**: Mobile-first design with Gen Z aesthetic and smooth animations
- **SEO Optimization**: Dynamic meta tags with Open Graph and Twitter Card support
- **Social Sharing**: Optimized content sharing across social media platforms
- **Performance**: Optimized for fast loading and smooth user experience

## Technical Architecture

### Frontend Stack
- **React 19.1.1**: Latest React with modern hooks and concurrent features
- **TypeScript 5.9.3**: Type safety and enhanced developer experience
- **Vite 7.1.7**: Fast development server and optimized production builds
- **Tailwind CSS 4.1.14**: Utility-first styling with custom design tokens
- **Radix UI**: Accessible component primitives for consistent UI

### Backend Infrastructure
- **Firebase Firestore**: NoSQL document database for scalable content storage
- **Firebase Auth**: Secure authentication with Google OAuth integration
- **Firebase Storage**: Media file storage with security rules
- **Firebase Hosting**: CDN-powered hosting with automatic deployments

### Key Components
- **RichTextEditor**: Tiptap-based rich text editor for blog content
- **MetaTags**: Dynamic SEO and social sharing optimization
- **DashboardLayout**: Admin interface with navigation and analytics
- **Content Management**: Firebase-integrated CRUD operations
